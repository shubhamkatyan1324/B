# ✨ Dynamic Birthday Celebration Website

A dynamic, modern, and heartfelt Birthday Wishing web application built with **React**, **Tailwind CSS**, and **Vite**, featuring all 18 photos from `pics/attachments`.

## 🎨 Modern Color Palette
- **Sage Green** (`#7D9D8B`, `#476251`, `#E6EDE8`) — Earthy tranquility and gentle warmth.
- **Electric & Royal Azul** (`#2563EB`, `#1E40AF`, `#0070F3`) — Radiant sky & festival illuminations.
- **Velvet Wine Red** (`#722035`, `#881337`, `#420D1C`) — Deep affection and celebratory luxury.
- **Blush / Light Pink** (`#FCE7F3`, `#FBCFE8`, `#FDA4AF`) — Sweetness, joy, and tenderness.
- **Champagne Gold** (`#F59E0B`, `#FDE68A`) — Sparkling candle flame accents and confetti.

---

## 🌟 Key Features

1. **Floating Celebration Balloons & Ambient Lighting**:
   - Soft glassmorphic light orbs with gentle pulsation.
   - Smooth swaying balloons floating in modern sage, azul, wine red, and blush pink.

2. **Celebration Hero Header**:
   - Dynamic typography with Google Fonts (*Playfair Display*, *Dancing Script*, and *Outfit*).
   - Dynamic photo trio featuring key moments under fairy lights.
   - Live counter badges (*365+ Days of Sunshine*, *18 Memories*, *100% Happiness*).

3. **Built-in Web Audio Synthesizer**:
   - Acoustic/synthesized playback of the "Happy Birthday" melody (runs in browser with zero external audio file breakages).
   - Audio effects for candle blowing (whoosh of air + chime bells), popping balloons, and gift unboxing.
   - Mute and Play/Pause toggles right in the navigation bar.

4. **Interactive Birthday Cake & Candle Ritual**:
   - 3D-styled tiered cake with flickering flame animations.
   - Click individual candles to blow them out, or click **"Blow Out All Candles & Make a Wish"** for full celebratory whoosh + confetti burst.
   - Realistic smoke wisps appear once candles are blown out.
   - Reveals a secret **"Lock in a Secret Wish"** time-capsule input with confirmation.
   - Relight candles button to experience the ritual again.

5. **Treasured Memories Gallery (All 18 Photos)**:
   - **Continuous Rolling Filmstrip Ticker**: Marquee of all 18 photos from `pics/attachments`.
   - **Filter Tabs**: *All (18)*, *Nights & Magic*, *Sweet Smiles*, *Special Moments*, *Adventures*.
   - **Polaroid Pinboard Mode**: Authentic polaroid frames with washi tape accents in Sage, Azul, and Wine Red, tilt angles, handwritten captions, and like buttons.
   - **Cinema Slideshow Mode**: Large high-resolution carousel with automated play, progress dots, and captions.
   - **Fullscreen Lightbox**: Click any photo to inspect it in high resolution with personalized notes.

6. **"Why You Are Incomparable" Cards**:
   - 6 glassmorphic appreciation cards highlighting electric smiles, gentle soul, playful spirit, grace, and shared dreams.
   - Interactive confetti bursts upon clicking any card.

7. **Virtual Gift Box & Birthday Passes**:
   - 3D gift box with ribbons and bow.
   - Click to unwrap with popping sound effect and confetti.
   - Reveals 4 redeemable passes (*"One Free Dream Date"*, *"Midnight Ice Cream Run"*, *"10,000 Warm Hugs"*, *"One Movie Night Choice"*).

8. **Birthday Letter with Wax Seal**:
   - Vintage-modern envelope with a heart wax seal.
   - Click to break the wax seal and reveal a heartfelt letter.
   - Built-in edit button allowing instant on-screen personalization.

9. **Customizable Name**:
   - Click the pencil icon next to the name in the header or in the modal to change the recipient's name to any nickname or title in real time.

## 🚀 How to Run Locally

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start Vite development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
